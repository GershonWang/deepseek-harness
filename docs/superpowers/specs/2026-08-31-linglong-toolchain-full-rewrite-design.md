## 背景与目标

### 背景

当前 DeepSeek Harness 玲珑客户端（`com.deepseek.dsh-desktop`）随包内置了一部分工具链，但存在以下问题：

1. **包体过大**：uab 包 431 MB，解压后 1.1 GB，其中大量是意外夹带的编译工具链（gcc-12 完整工具链 ~140 MB）和构建残留（node 头文件 ~67 MB、experimental 包、typescript 等）。
2. **工具链供给方式单一**：只有随包内置 + 手动宿主挂载两种方式，没有中间的「按需安装」生态。
3. **用户体验差**：工具链散落在各处，用户不知道有哪些、怎么装、装了怎么用。

### 目标

- **体积**：主模块从 431 MB 瘦身到 ~150 MB
- **体验**：所有工具链统一在「工具市场」管理，分类浏览、一键安装/卸载/切换版本
- **热插拔**：L2 工具装完新 shell 立刻生效，不需要重启应用
- **可扩展**：工具清单通过远程索引更新，不需要发客户端版本
- **项目级**：支持项目级工具版本配置（类似 asdf 的 .tool-versions）

### 非目标

- 不做玲珑原生 modules/extensions 机制的工具化（工具市场是应用层功能）
- 不做运行时沙箱内动态 mount（玲珑不支持）
- 不做完整的「应用商店」体验（只做轻量级工具市场弹框）

## 整体架构

三层工具供给，PATH 优先级从低到高：

```
┌─────────────────────────────────────────────────────┐
│ L1 内置（玲珑只读层）                                │
│ 启动器 + node + dsh + git + python + curl + ...      │
│ ~150 MB · 构建时确定 · PATH 优先级最低               │
└─────────────────────────────────────────────────────┘
                          ↑
┌─────────────────────────────────────────────────────┐
│ L2 一键安装（工具市场）                               │
│ ~/.d-sh-tools/ · HOME 共享持久化                     │
│ 多版本 · 依赖 · sha256 校验 · 原子安装               │
│ 装完新 shell 立刻生效 · PATH 优先级中等              │
└─────────────────────────────────────────────────────┘
                          ↑
┌─────────────────────────────────────────────────────┐
│ L3 宿主导入（config.d bind 挂载）                    │
│ /opt/host-tools/ · 只读 rbind                       │
│ 需重启应用生效 · PATH 优先级最高                    │
└─────────────────────────────────────────────────────┘
```

### 核心组件

| 组件 | 位置 | 职责 |
|------|------|------|
| toolchain/catalog.go | Go | 工具清单 · 多版本管理 · 安装/卸载 · 软链自愈 |
| toolchain/install.go | Go | 下载 · sha256 校验 · tar.gz 解包 · 原子安装 |
| toolchain/catalog.go Catalog() | Go | 内置工具清单（从 tools.yaml 生成） |
| appenv/env.go | Go | PATH & LD_LIBRARY_PATH 注入 · 三级优先级排序 |
| hosttools/hosttools.go | Go | config.d 挂载管理 · 冲突检测 |
| app/app.go | Go | Wails 绑定层 · 市场 UI 接口 |
| frontend/app.js | JS | 工具市场弹框 UI · 安装进度 · 版本切换 |
| tools.yaml | 配置 | 工具清单单一数据源 |

## L2 工具核心组件设计

### 目录结构

```
~/.dsh-tools/
├── bin/                      # 激活版本的命令软链（进 PATH）
├── lib/                      # 激活版本的库软链（进 LD_LIBRARY_PATH）
├── current/                  # 各工具激活版本的软链
│   ├── gcc -> ../gcc-12.3.0
│   └── ...
├── gcc-12.3.0/               # 版本化安装目录
│   ├── bin/
│   ├── lib64/
│   └── tool.yml
├── gcc-13.2.0/               # 多版本并存
├── cache/                    # 下载缓存（按 sha256 命名）
│   └── abc123...tar.gz
├── index.json                # 远程索引缓存
└── index.json.etag           # 索引缓存 etag
```

### 工具元数据格式（tool.yml / 远程索引）

```yaml
id: gcc
name: GCC 编译器
category: compiler
description: GNU Compiler Collection，包含 C/C++/Fortran/Go 等前端。
provides: [gcc, g++, cpp, gcov, c++filt, gcc-ar, gcc-ranlib]
size: 150MB
dependencies: [make, binutils]

versions:
  - version: 12.3.0
    url: https://.../gcc-12.3.0-x86_64-linux-gnu.tar.gz
    sha256: abc123...
    bin_rel: gcc-12.3.0/bin
    lib_rel: gcc-12.3.0/lib64
  - version: 13.2.0
    url: https://.../gcc-13.2.0-x86_64-linux-gnu.tar.gz
    sha256: def456...
    bin_rel: gcc-13.2.0/bin
    lib_rel: gcc-13.2.0/lib64
```

### 安装流程（原子操作）

```
开始
  ↓
检查下载缓存 → 没有就下载（带进度，可取消）
  ↓
sha256 校验 ──失败──→ 报错 + 清缓存 + 重试按钮
  ↓ 成功
解压到临时目录（~/.dsh-tools/.install-xxx/）
  ↓
校验顶层目录结构 + 防路径穿越
  ↓
原子移动到最终位置（同分区 rename）
  ↓
首次安装或指定激活？
  ├─ 是 → 更新 current/ 软链 → 重建 bin/ 和 lib/ 软链
  └─ 否 → 仅安装，不激活
  ↓
写下载缓存
  ↓
完成
```

### 卸载流程

```
移除 current/<name> 软链
  ↓
移除 bin/ 和 lib/ 里对应的软链
  ↓
删除版本目录
  ↓
还有其他版本？
  ├─ 是 → 自动激活最新的
  └─ 否 → 结束
```

### 依赖处理（单层）

- 每个工具可声明 `dependencies: [make, binutils]`
- 安装时：遍历依赖列表，未安装的自动触发安装
- 卸载时：提示「有 N 个工具依赖它」，用户确认后再卸
- 只做一层，不做递归依赖树（工具之间依赖不深）
- 循环依赖检测：如果 A 依赖 B，B 依赖 A → 报错

### 启动自愈（ReconcileBinLinks）

应用启动时调用：
1. 扫描 `current/` 下所有工具
2. 重建 `bin/` 里所有可执行文件的软链
3. 重建 `lib/` 里库文件的软链（如果工具有 lib_rel）
4. 清理失效的软链
5. 保证重装/更新/HOME 迁移后工具链仍可用

## 工具市场 UI 设计

### 布局（弹框，约 900×620）

**左侧分类栏（160px）**：
- 全部分类（显示总数）
- 编译工具 / 语言 SDK / 现代 CLI / 调试分析 / 代码质量
- 宿主导入（向导页入口）
- 已安装 / 工具集（特殊分类）

**右侧主内容区**：
- 顶部：搜索框 + 关闭按钮
- 热门工具集推荐（3 个卡片）
- 工具卡片网格（3 列）
  - 已安装：绿色边框 + 版本切换下拉 + 卸载按钮
  - 未安装：灰色边框 + 大小/依赖 + 安装按钮
- 底部状态栏：已安装数 + 总大小 + 提示

### 交互

- 安装有进度反馈（下载% + 解压中）
- 安装失败显示错误 + 重试
- 切换版本后提示「重开 terminal 或执行 hash -r 生效」
- 卸载有二次确认
- 工具集一键安装（自动装一组，显示总大小）
- 搜索：按名称/描述模糊匹配

### 宿主导入向导页

- 自动扫描宿主常见目录（/usr/bin, /usr/local/bin, ~/.local/bin, /opt/*）
- 列表展示发现的工具 + 版本
- 用户勾选要导入的
- 一键生成 config.d 配置
- 明确提示「导入后需重启应用才能生效（玲珑沙箱限制）」
- 冲突检测：和已装 L2 工具重名时高亮提示（宿主挂载优先级更高）

## 远程索引

### 索引格式（JSON）

```json
{
  "version": 1,
  "updated_at": "2026-08-31T00:00:00Z",
  "tools": [...],   // 工具列表，格式同 tool.yml
  "bundles": [...]  // 工具集
}
```

### 加载策略（混合模式）

1. 应用启动时**异步**拉取远程索引（不阻塞 UI）
2. 拉取成功 → 存入本地缓存（`~/.dsh-tools/index.json`）
3. 拉取失败 → 使用上次缓存
4. 缓存也没有 → 使用**内置的 tools.yaml**（兜底）
5. 缓存有效期 24 小时，过期自动刷新

### 下载缓存

- 下载过的 tar.gz 存在 `~/.dsh-tools/cache/`
- 按 sha256 值命名，避免重复下载
- 缓存上限 500 MB，超了按 LRU 清理最老的

## 项目级工具配置

### 配置文件

项目根目录放 `.dsh-toolchain.yml`：

```yaml
# 项目需要的工具和版本
tools:
  go: "1.23.2"
  gcc: "12.3.0"
  python: "3.11"

# 是否自动切换版本（默认 true）
auto_switch: true

# 缺少工具时是否自动提示安装（默认 true）
auto_prompt: true
```

### 检测逻辑

- harness 打开项目时（工作目录变化），启动器向上查找配置文件
- 找到后：
  - 缺工具 → 弹 toast 提示「本项目需要 X/Y/Z 工具，一键安装？」
  - 版本不匹配 → 自动切换到配置的版本（已装的话），没装就提示安装
- 用户可以选择「忽略此项目」
- 配置优先级：项目级 > 用户全局默认

## 体积瘦身方案

目标：431 MB → ~150 MB

| # | 项目 | 预计节省 | 实施方案 | 风险 |
|---|------|---------|---------|------|
| 1 | 剥离 gcc 完整工具链 | ~140 MB | 分析 buildext.apt.depends 依赖链，找到 gcc 源头，exclude 掉 gcc-12 包。保留 libgcc_s.so / libstdc++.so 等运行时 .so | 中 |
| 2 | 删除 node/include/ | ~67 MB | node-pty 编译完之后删 `node/include/` | 低 |
| 3 | 过滤 experimental 包 | ~13 MB | inject_workspace_pkg 跳过 `packages/experimental/` | 低 |
| 4 | 注入包只拷 lib/ | ~10 MB+ | 注入时只复制 lib/ + package.json + README，不拷 src/tests/tsconfig | 低 |
| 5 | 剔除 typescript | ~24 MB | 生产闭包里删掉 typescript（运行时不需要，.ts 已编译成 .js） | 中 |
| 6 | 剔除 sharp/@img | ~19 MB | 确认非 runtime 必需后剔除 | 中 |
| 7 | node 二进制 strip | ~20-40 MB | strip node/bin/node 剥调试符号 | 低 |

实施顺序：先做低风险（2/3/4/7）→ 验证 → 再做中风险（1/5/6）。

## 错误处理

| 场景 | 处理方式 | 用户可见 |
|------|---------|---------|
| 下载失败（网络/超时） | 重试按钮 + 错误详情 | 红色错误条 |
| sha256 校验失败 | 清缓存 + 重试按钮 | 红色错误条 |
| 磁盘空间不足 | 提示所需空间 + 当前剩余 | 警告弹窗 |
| 依赖安装失败 | 已装的依赖保留 + 提示哪个失败 | 错误提示 |
| 路径穿越检测 | 直接报错 + 清临时文件 | 错误提示 |
| 循环依赖 | 报错 + 不安装 | 错误提示 |
| 远程索引拉取失败 | 降级使用缓存/内置清单 | 静默（不打扰用户） |
| 宿主导入后未重启 | 状态图标标灰 + hover 提示「重启生效」 | 状态提示 |
