# Agent Note: 桌面启动器工具链市场的呈现

Status: implemented

[English](2026-09-12-desktop-launcher-toolchain-market-presentation.md) | 中文

## 问题

工具链市场弹框带着一批呈现缺陷，放在壳的其余部分旁边一眼就像未完成。以下是在 Chromium 里按随包目录（19 个工具）实测的结果：

- `分类 · 命令 · 体积` 这一行从未渲染。`.tool-card-meta` 带 `overflow: hidden`，这会把该弹性子项的自动最小尺寸降为 0，使它成为整列唯一可压缩的行；卡片被 `min-height: 120px` 钉住时该列差 14px，于是这一行在每张卡上都是 0px。
- 按钮与表单控件不继承壳的字体栈。`button`/`input`/`select` 自带 UA 的 `font` 声明，而元素上的声明胜过从 `body` 继承的值：`.btn`、`.market-tab`、`#market-search`、`.version-select`、`#host-path` 的计算字体是 Arial，正文则是 Noto Sans CJK 栈。
- 禁用态的安装按钮——用户盯着一个 1.5 GB SDK 下载时看到的就是它——是品牌底加 `opacity: .4` 的白字，实测 2.29:1。
- 只有 `.btn` 与 `.host-row input` 有 `:focus-visible` 焦点环。分类页签落到 UA 默认环（`auto 1px rgb(16,16,16)`，在 `#252526` 上不可辨认），搜索框与版本下拉仅在聚焦时换边框色。
- 切换分类会改变弹框尺寸，因为它的高度跟着卡片网格走：19 张卡顶到 `max-height: 86vh`，只剩一张卡的分类不到它的一半。
- 宿主导入区——只在玲珑沙箱内存在的高级路径——常驻展开，占掉弹框底部六分之一。
- 每张已安装卡片都描一圈绿边。已安装在这里是常态（19 张里 11 张），于是这个强调什么也没标记，而 `可更新` 又在同一个色系里跟它抢注意力。
- 空态是一行靠左的灰字、没有下一步；最后一个断点是 760px 的两列；网格用的是平台默认滚动条。
- 深色品牌填充色 `#4d6bfe` 上的白字是 4.33:1，低于 12px 文字 4.5:1 的门槛；[主题 token 审计](../bug-fix/2026-09-11-desktop-launcher-theme-tokens.zh.md)把这条记为一个已知缺口。

## 决策

卡片高度改为覆盖卡片可能容纳的最高内容。网格滚动时行高是按卡片的 `min-height` 量的——内容超过它的部分会溢出卡片，而不会把行撑高——因此四行内容取 `141px`，带运行时提示的卡片经 `.has-runtime` 取 `160px`。`.tool-card-meta` 与 `.tool-card-runtime` 拒绝收缩，描述截两行，任何输入都无法把元信息行挤出去。

表单控件在 `body` 之后统一 `font: inherit`。自己声明过字号的控件（`.btn` 12px、`.market-tab` 12px、`.builtin-toggle` 11px、`.version-select` 11.5px）保持原样，其余跟随 13px 的壳字号。

禁用态按钮改为中性底加弱化但仍可读的文字（`color-mix(in srgb, var(--fg) 75%, var(--bg-input))`）：深色 4.64:1、浅色 5.25:1。"正在进行"由卡片上的进度条承担，不再靠按钮自己褪色。

覆盖 `.btn` 与 `.host-row input` 的 `:focus-visible` 规则扩到 `.market-tab`、`.builtin-toggle`、`#market-search` 与 `.version-select`。

市场弹框定在 `height: 86vh`，与它的 `max-height` 同值。卡片最多的分类本来就顶到这个上限，因此这个修复不改变最常见的那一档视图，只把矮分类的空白留在弹框内，滚动交给网格。

宿主导入折叠成一行：箭头、标题，以及报出 `已挂载 N 项` 的摘要。`aria-expanded` 由正文自身的折叠态推导，不在 HTML 与 JavaScript 里各记一份。

强调色留给两种需要用户动作的状态：`updatable` 取 warn 描边，`installing` 取品牌描边。`installed` 仍留在卡片上作为状态标记，不带样式。

无结果时渲染居中的结论、一句引导与 `清空筛选` 按钮；按钮只在真的设了筛选条件时出现，目录本身为空时不会让人以为是自己筛掉的。设了筛选时状态栏报出 `筛选 N 个`，页签与搜索框都走 `refreshMarketView()`，这个数字不会停在旧值。

网格在 760px 退回两列、560px 退回单列；滚动条取 10px，滑块用 `--border-strong`（悬停 `--fg-dim`）并以透明边框内缩，同时声明 `scrollbar-width`/`scrollbar-color` 与 `::-webkit-scrollbar`。

深色 `--brand` 从 `#4d6bfe` 移到 `#4763f0`：白字在它上面 4.87:1，按钮相对卡片底 `#252526` 仍有 3.14:1，即非文字控件的 3:1 门槛。浅色 `--brand` `#2547d0` 不变，7.26:1。

## 备选方案

**像服务器弹框那样把网格做叠放。** 那套用"量更高的那张面板"来解决"内容互换而外框不动"。否决：市场的内容是长度可变的列表，不是两张互斥面板，没有更高的那一半可量。

**只给元信息行加 `flex-shrink: 0`。** 一行声明，不动高度。按实测否决：141px 的卡片下内容反而多要 6px，元信息行回来了，卡片却溢出了。

**去掉卡片 `min-height`，让每行都由内容决定。** 否决（实测）：行高落到 60px，19 张卡全部溢出；网格一旦滚动，这里的行高不跟随内容。

**把每张卡的 `min-height` 统一抬到 160px。** 不需要第二档，也是对的。否决：它给每张没有运行时提示的卡片都花掉 19px 空白，而大多数卡片没有提示。

**禁用态保留 `opacity`，只把它提到 0.6。** 最贴近原代码。否决：opacity 同时淡化底色与文字，深色下文字仍不到 4.5:1，而按钮自己的底色先被洗掉。

**给深色按钮单独一个填充 token，不动 `--brand`。** 品牌填充色可以一个字节都不变。否决：同一个壳里两个品牌填充色只差 4%，迟早会各自漂移；这点差异肉眼不可辨，而其余每一处 `--brand` 实底（品牌点、胶囊、页签、安全模式块）都落在同一个实测对比上。

**把 `--brand` 再压深到 `#4055d6`。** 白字能到 6.02:1。否决：按钮相对卡片底掉到 2.54:1，低于 3:1 非文字门槛，按钮会陷进深色卡片。

**安装按钮按内容宽、右对齐，不撑满动作行。** 按钮能保持小巧。否决：那一行的可伸缩项是版本下拉，于是未安装卡片只挂一个短按钮、相邻卡片挂一个满宽下拉，整列动作行对不齐。

**只要有挂载项就默认展开宿主导入。** 符合"配置了就该看见"。否决：折叠状态会跟着工具链事件翻转，弹框会自己动。

**保留已安装卡片的绿描边。** 最省事。否决：19 张里 11 张已安装，强调落在常态上，`可更新` 正是因此才难找。

## 后果

卡片比先前高 21px（141px 对 120px），含运行时提示卡片的那一行是 160px，一屏因此少显示约半行。弹框固定 86vh：只剩一张卡的分类现在表现为框内的空白，而不是更小的框——`筛选 N 个` 与空态正是为解释这片空白而存在。

禁用态的安装按钮失去品牌填充色，因此进行中的安装读起来是"这个动作现在不可用"，而不是"正在发生什么"；这层含义由进度条与它的百分比承担。

深色品牌填充色在它被当作填充色的每一处都暗了 4%，不只是按钮。浅色主题未受影响。

元信息行与运行时提示现在都吃高度，因此将来若要在卡片里加第五行，必须同时抬高 `min-height` 档次，否则卡片会裁切而不是长高。

## 测试

`node --test frontend/test-app.cjs` 跑 37 例，其中三例是新增的：宿主导入初始折叠、点击展开与收起且 `aria-expanded` 跟随、摘要报出挂载项数；无结果时渲染清空筛选按钮，点击后搜索框复位并恢复全部卡片。DOM 桩补了 `hosts-toggle`、`hosts-body`、`hosts-summary` 三个 id 与正文的初始 `hidden` 态。空态那例按网格自身的子节点断言，因为桩的 `querySelector` 扫的是元素注册表，`innerHTML = ""` 移除的元素它照样找得到。

布局、主题与对比度由在 Chromium 里渲染 `frontend/index.html` 来验证：本环境中 `~/.cache/ms-playwright/chromium-1234/chrome-linux64/chrome` 可以启动，因此该脚本加载真实样式表、把 19 个工具的载荷交给 `renderTools`，并在两套配色下各断言 36 项——四个分类下弹框高度一致、无卡片溢出、元信息行可见、控件字体等于正文栈、禁用态与主按钮对比、卸载按钮两击宽度不变、焦点环为 2px 实线、可更新与安装中的描边互不相同、宿主导入折叠、空态、筛选计数，以及 3/2/1 列断点。它自己调用 `setupHostsToggle()`，因为浏览器预览会在绑定之前就从 `init()` 返回。

该脚本替代了此前启动器笔记不得不要求的 `make build` 目视一轮；它不能替代运行打包后的应用，后者仍是确认 webkitgtk 专有渲染的手段。
