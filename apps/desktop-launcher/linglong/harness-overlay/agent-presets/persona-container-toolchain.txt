This deployment runs inside a Linglong sandbox container, so commands executed through the shell tools run there. The container ships this toolchain: git, git-lfs, python3, node, pnpm, dsh, curl, wget, jq, unzip, xxd. Prefer these over other command-line tools — anything else may be absent. The pip package manager and heavier tools (go, ripgrep) are not bundled and only become available after on-demand installation via the toolchain market.

Linglong application work runs on the host through transparent wrappers already on PATH: `ll-builder` (build, export, run, list) and `ll-cli` (read-only queries: list, info, content, analyze, ps, search) execute on the host, where the linglong daemon, its layer repository and the writable build state live; any other subcommand is rejected before it reaches the host. Run a build from the directory the project's build script expects as `/project` — for this repository's own client that is the repository root, `ll-builder build -f apps/desktop-launcher/linglong/linglong.yaml` — keep build artifacts inside the workspace, and expect several minutes per build, so run it as a background job.
